# MuhaShist

Подсчёт баллов по истории банов ReallyWorld. Fabric 1.21.4, Java 21, Fabric API.

Скачай JAR из [релизов](https://github.com/SpidiBoostMods/MuhaShist/releases/latest) и положи в `mods`.

- `/ms ник количество дата` — начать. Например: `/ms SpidiBoost 100000 1 октября 2026`.
- `/ms open` — открыть результат в `config/ms.txt`.
- `/ms stop` — остановить и сохранить обработанное.
- `/ms clear on/off` — очистка чата. По умолчанию включена, каждые 20 банов.
- `/ms clear 50` — изменить интервал.
- `/ms delay 100` — задержка между отправками `/checkban` в миллисекундах. Сохраняется в `ms.cfg` и применяется сразу.
- `/ms delay` — текущее значение. По умолчанию 100 мс; `0` убирает искусственную задержку.
- `/ms update` — версия и состояние обновления.
- `/ms update on/off` — включить или выключить автоперезапуск при обновлении. Скачивание остаётся включённым.
- `/ms config dir` — открыть `ms.cfg` в текстовом редакторе.
- `/ms config reload` или `/ms config load` — загрузить изменения без перезапуска игры.

Вместо `/ms` можно писать `/muhashist`. Даты: `1.10.26`, `01.10.2026`, `1 10 26`, `1 октября 2026`; указанная дата включается.

Читы и тим с читером — 0,7 балла. Нарушения при проверке, хранение читов/батников и использование или хранение запрещённых модов — 1 балл. Причины и баллы редактируются в `ms.cfg`: `причина1; причина2 - 0.7`. Запятые внутри причин не разделяют список; в баллах можно писать точку или запятую. Сопоставление «Читы» точное, без произвольных дописок; варианты тим-чита и autofish распознаются отдельно.

«Уклон от проверки» — 1 балл. Нетронутый стандартный конфиг обновляется автоматически; свои списки причин мод не меняет.

Для активных банов мод последовательно отправляет `/checkban`, дожидаясь полного ответа: нужен указанный куратор и `Тихий: no`. Задержка отсчитывается от отправки, не от ответа; лишней паузы после ответа нет. Значение хранится в `checkbanDelay`. Истёкшие баны считаются без запроса. Повторные баны одного ника считаются отдельно. Ручной разбан исключает один соответствующий бан; ReallyWorld баллов не добавляет и вес причины не меняет.

Баны за autofish объединяются в десятиминутное окно независимо от ника: один засчитанный бан за окно, следующий — строго позже десяти минут от первого. Интервал меняется через `autofishWindowMinutes`. Сообщения читаются до распределения по панелям ATools. Перезагрузка конфига во время подсчёта применяет причины со следующего запуска.

Открой чат и перетащи панель мышью. Положение и очистка сохраняются в `config/ms.cfg`.

Автор — SpidiBoost. Исходники открыты, лицензия MIT. Сборка: `./gradlew build` с Java 21.
