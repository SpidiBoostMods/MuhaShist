MuhaShist 1.1.3 · Fabric 1.21.4

- /ms delay мс — настройка задержки между отправками checkban с сохранением в ms.cfg.
- По умолчанию 100 мс. Новое значение применяется сразу, без дополнительной паузы после ответа.
- /ms delay — посмотреть значение; 0 — убрать искусственную задержку. Очередь остаётся последовательной.
